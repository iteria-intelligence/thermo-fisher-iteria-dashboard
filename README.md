# Thermo Fisher × Iteria laboratory intelligence dashboard

A static HTML, CSS and JavaScript dashboard, published with GitHub Pages. No server, account sign-in or build step is required.

## Content

- Analytics: illustrative operational charts, activity portions and setup scenarios.
- Original videos: source recordings, short excerpts and a sampled-frame library.
- Black theme, entrance animations and responsive layout.

The operational chart values are synthetic demo data, not measured Thermo Fisher results. The 1,000-hour collection figure is supplied by the team. Workflow automation savings are planning assumptions. Source videos and evidence frames come from the supplied analysis material.

## Preview

Run `python3 -m http.server 8080` in this directory and open `http://localhost:8080/`.

## Publish

GitHub Pages serves the repository root from the `main` branch. All asset paths are relative so the site works under a GitHub Pages project URL.
